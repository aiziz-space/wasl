# وصل.

انقل الصور والملفات بين جوالك وكمبيوترك على نفس الواي فاي. امسح رمز واسحب الملفات — بدون تطبيق وبدون حساب.

**افتحه:** https://aiziz-space.github.io/wasl/

- الملفات تنتقل مباشرة بين الجهازين (WebRTC) بقناة مشفّرة، وما تُحفظ في أي خادم.
- يشتغل على آيفون وأندرويد وماك وويندوز بأي متصفح حديث.

للمطورين: التفاصيل التقنية في `CLAUDE.md`، والاختبارات: `bash tests/run.sh`.
